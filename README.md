# Faste – vaner og vekt

En enkel norsk PWA for å registrere fastedager, kommentarer og vekt.

## Funksjoner
- Kalender med grønn (fastet til middag), gul (delvis) og rød (ikke fastet) status.
- Kommentar per dag.
- Vektregistrering på valgfri dato, med graf og historikk.
- Eksport/import av sikkerhetskopi.
- Lokal lagring i nettleseren og enkel offline-støtte.

## Publisering
Aktiver GitHub Pages fra Settings → Pages → Deploy from a branch → main → /(root).

På iPhone: åpne Pages-adressen i Safari, trykk Del → Legg til på Hjem-skjerm.

Data lagres lokalt på enheten og synkroniseres ikke automatisk mellom enheter.
